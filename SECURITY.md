# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private reporting:
**Security tab -> Report a vulnerability**.

We aim to acknowledge reports within 3 days and give a fix timeline within 14 days.

## Supported versions

Only the latest release receives security fixes.

## Scope

patchlint reads files and prints findings; it never executes scanned content.
Reports about crashes or resource exhaustion on malicious input files are in scope.
